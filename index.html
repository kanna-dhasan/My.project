About DSA

DSA stands for Data Structures and Algorithms.

Data Structure is used to store and organize data. Algorithm is a step-by-step procedure used to solve a problem.

Data Structures

1. Array

Array stores multiple elements of the same type in a continuous memory location.

Example: 10, 20, 30, 40, 50

2. Linked List

Linked List contains nodes. Each node stores data and a link to the next node.

3. Stack

Stack follows LIFO — Last In First Out.

Operations: Push, Pop, Peek

4. Queue

Queue follows FIFO — First In First Out.

Operations: Enqueue, Dequeue

5. Heap

Heap is a tree-based data structure. Types: Min Heap and Max Heap.

Sorting Algorithms

Bubble Sort

Compares adjacent elements and swaps them when they are in the wrong order.

Insertion Sort

Takes one element at a time and places it in the correct position.

Merge Sort

Divides the array into smaller parts, sorts them and merges them together.

Searching Algorithms

Linear Search

Checks each element one by one until the required element is found.

Binary Search

Searches a sorted array by repeatedly dividing the search area into two parts.

Tree Data Structure

Binary Tree

A tree in which each node can have at most two children.

Complete Binary Tree

All levels are completely filled except possibly the last level.

B-Tree

B-Tree is a balanced search tree commonly used for efficient searching and storage.

Important DSA Concepts

Time Complexity

Time complexity describes how the running time of an algorithm grows with input size.

Common examples: O(1), O(log n), O(n), O(n log n), O(n²)

Space Complexity

Space complexity describes the amount of memory required by an algorithm.
